# Olist Brazilian E-Commerce
An end-to-end data analytics and business intelligence project built on the Brazilian Olist Store e-commerce dataset, demonstrating an enterprise analytics workflow across the full data lifecycle:

Data Engineering & Preprocessing (Python & Pandas): Handling data ingestion, cleansing, Portuguese Unicode/accent normalization, missing value imputation, and temporal feature extraction.

Relational Database Management (MySQL Server): Designing a normalized relational schema, enforcing primary/foreign key constraints, and executing analytical SQL queries to aggregate key business metrics.

Ad-Hoc Analysis & Auditing (Microsoft Excel): Conducting exploratory data auditing, quick reconciliations, and isolated comment text inspections.

Enterprise Reporting & Interactive Dashboards (Power BI & Tableau): Building dimensional star schemas, engineering DAX measures for financial and operational KPIs, and delivering interactive visualizations in both Power BI and Tableau for executive decision-making.
